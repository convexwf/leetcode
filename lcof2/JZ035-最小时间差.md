# 剑指 Offer II JZ035-最小时间差

## 题目描述

<!-- description:start -->

<p>给定一个 24 小时制（小时:分钟 <strong>&quot;HH:MM&quot;</strong>）的时间列表，找出列表中任意两个时间的最小时间差并以分钟数表示。</p>

<p>&nbsp;</p>

<p><strong>示例 1：</strong></p>

<pre>
<strong>输入：</strong>timePoints = [&quot;23:59&quot;,&quot;00:00&quot;]
<strong>输出：</strong>1
</pre>

<p><strong>示例 2：</strong></p>

<pre>
<strong>输入：</strong>timePoints = [&quot;00:00&quot;,&quot;23:59&quot;,&quot;00:00&quot;]
<strong>输出：</strong>0
</pre>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>2 &lt;= timePoints &lt;= 2 * 10<sup>4</sup></code></li>
	<li><code>timePoints[i]</code> 格式为 <strong>&quot;HH:MM&quot;</strong></li>
</ul>

<p>&nbsp;</p>

## 解题思路

1. 将所有时间转换为分钟数（从00:00开始计算）。
2. 对分钟数数组进行排序。
3. 遍历排序后的数组，计算相邻两个时间的差值，取最小值。
4. 特别注意：还需要计算首尾时间的跨天差值（即 `1440 + first - last`）。

时间复杂度：$O(n \log n)$，主要是排序的时间复杂度。空间复杂度：$O(n)$，存储转换后的分钟数。

```cpp
class Solution {
public:
    int findMinDifference(vector<string>& timePoints) {
        vector<int> minutes;
        
        // Convert all times to minutes
        for (const string& time : timePoints) {
            int h = stoi(time.substr(0, 2));
            int m = stoi(time.substr(3, 2));
            minutes.push_back(h * 60 + m);
        }
        
        // Sort the minutes
        sort(minutes.begin(), minutes.end());
        
        // Find minimum difference
        int minDiff = INT_MAX;
        for (int i = 1; i < minutes.size(); i++) {
            minDiff = min(minDiff, minutes[i] - minutes[i-1]);
        }
        
        // Check wrap-around difference (first and last)
        minDiff = min(minDiff, 1440 + minutes[0] - minutes.back());
        
        return minDiff;
    }
};
```
