## Code

1. 构造函数中创建二维前缀和数组 `preSum`，大小为 `(m+1) x (n+1)`，多出一行一列用于处理边界情况。
2. `preSum[i][j]` 表示从 `(0,0)` 到 `(i-1,j-1)` 的矩形区域元素总和。
3. 使用公式：`preSum[i][j] = preSum[i-1][j] + preSum[i][j-1] - preSum[i-1][j-1] + matrix[i-1][j-1]` 计算前缀和。
4. 查询子矩阵和时，使用公式：`preSum[row2+1][col2+1] - preSum[row1][col2+1] - preSum[row2+1][col1] + preSum[row1][col1]`。
5. 时间复杂度：构造 $O(m \times n)$，查询 $O(1)$。

```cpp
class NumMatrix {
public:
    NumMatrix(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        preSum = vector<vector<int>>(m + 1, vector<int>(n + 1, 0));
        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                preSum[i][j] = preSum[i - 1][j] + preSum[i][j - 1] - preSum[i - 1][j - 1] + matrix[i - 1][j - 1];
            }
        }
    }

    int sumRegion(int row1, int col1, int row2, int col2) {
        return preSum[row2 + 1][col2 + 1] - preSum[row1][col2 + 1] - preSum[row2 + 1][col1] + preSum[row1][col1];
    }

private:
    vector<vector<int>> preSum;
};
```
