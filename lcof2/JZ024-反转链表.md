## 解题思路

1. 使用迭代方法，维护三个指针：`prev`（前一个节点）、`curr`（当前节点）、`next`（下一个节点）。
2. 遍历链表，将每个节点的`next`指针指向前一个节点。
3. 移动三个指针继续处理下一个节点。
4. 最后返回新的头节点（原链表的尾节点）。

时间复杂度：$O(n)$，需要遍历一次链表。空间复杂度：$O(1)$，只使用常数额外空间。

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        
        while (curr != nullptr) {
            ListNode* next = curr->next;
            curr->next = prev;
            prev = curr;
            curr = next;
        }
        
        return prev;
    }
};
```
