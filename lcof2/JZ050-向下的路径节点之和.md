# 剑指 Offer II JZ050-向下的路径节点之和

## 题目描述

<!-- description:start -->

<p>给定一个二叉树的根节点 <code>root</code>&nbsp;，和一个整数 <code>targetSum</code> ，求该二叉树里节点值之和等于 <code>targetSum</code> 的 <strong>路径</strong> 的数目。</p>

<p><strong>路径</strong> 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。</p>

## 解题思路

1. 使用前缀和 + 哈希表的方法，记录从根节点到当前节点的路径上各个前缀和出现的次数。
2. 对于当前节点，如果存在前缀和 `currSum - targetSum`，说明存在一条路径和为 `targetSum`。
3. 递归遍历左右子树时，将当前前缀和加入哈希表，回溯时删除。
4. 累加所有满足条件的路径数量。

时间复杂度：$O(n)$，其中 $n$ 是二叉树的节点数，每个节点访问一次。空间复杂度：$O(h)$，其中 $h$ 是树的高度，哈希表最多存储高度个前缀和。

```cpp
class Solution {
private:
    int count = 0;
    unordered_map<long long, int> prefixSum;
    
    void dfs(TreeNode* root, long long currSum, int targetSum) {
        if (root == nullptr) return;
        
        currSum += root->val;
        
        // Check if there's a prefix sum that makes target
        if (prefixSum.count(currSum - targetSum)) {
            count += prefixSum[currSum - targetSum];
        }
        
        // Add current prefix sum
        prefixSum[currSum]++;
        
        // Recursively process children
        dfs(root->left, currSum, targetSum);
        dfs(root->right, currSum, targetSum);
        
        // Backtrack: remove current prefix sum
        prefixSum[currSum]--;
    }
    
public:
    int pathSum(TreeNode* root, int targetSum) {
        // Initialize with prefix sum 0 (for paths starting from root)
        prefixSum[0] = 1;
        dfs(root, 0, targetSum);
        return count;
    }
};
```
