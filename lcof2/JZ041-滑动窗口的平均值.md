# 剑指 Offer II JZ041-滑动窗口的平均值

## 题目描述

<!-- description:start -->

<p>给定一个整数数据流和一个窗口大小，根据该滑动窗口的大小，计算滑动窗口里所有数字的平均值。</p>

<p>实现 <code>MovingAverage</code> 类：</p>

<ul>
	<li><code>MovingAverage(int size)</code> 用窗口大小 <code>size</code> 初始化对象。</li>
	<li><code>double next(int val)</code>&nbsp;成员函数 <code>next</code>&nbsp;每次调用的时候都会往滑动窗口增加一个整数，请计算并返回数据流中最后 <code>size</code> 个值的移动平均值，即滑动窗口里所有数字的平均值。</li>
</ul>

<p>&nbsp;</p>

<p><strong>示例：</strong></p>

<pre>
<strong>输入：</strong>
inputs = [&quot;MovingAverage&quot;, &quot;next&quot;, &quot;next&quot;, &quot;next&quot;, &quot;next&quot;]
inputs = [[3], [1], [10], [3], [5]]
<strong>输出：</strong>
[null, 1.0, 5.5, 4.66667, 6.0]

<strong>解释：</strong>
MovingAverage movingAverage = new MovingAverage(3);
movingAverage.next(1); // 返回 1.0 = 1 / 1
movingAverage.next(10); // 返回 5.5 = (1 + 10) / 2
movingAverage.next(3); // 返回 4.66667 = (1 + 10 + 3) / 3
movingAverage.next(5); // 返回 6.0 = (10 + 3 + 5) / 3
</pre>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>1 &lt;= size &lt;= 1000</code></li>
	<li><code>-10<sup>5</sup> &lt;= val &lt;= 10<sup>5</sup></code></li>
	<li>最多调用 <code>next</code> 方法 <code>10<sup>4</sup></code> 次</li>
</ul>

<p>&nbsp;</p>

## 解题思路

1. 使用队列维护滑动窗口内的元素，用变量记录窗口内元素的总和。
2. 每次调用 `next(val)` 时，将新值加入队列并累加到总和中。
3. 如果队列大小超过窗口大小，移除队首元素并从总和中减去。
4. 返回总和除以队列大小，即为当前窗口的平均值。

时间复杂度：$O(1)$，每次操作都是常数时间。空间复杂度：$O(k)$，其中 $k$ 是窗口大小，需要存储窗口内的所有元素。

```cpp
class MovingAverage {
private:
    int size;
    queue<int> window;
    double sum;
    
public:
    MovingAverage(int size) {
        this->size = size;
        this->sum = 0;
    }
    
    double next(int val) {
        window.push(val);
        sum += val;
        
        // Remove oldest element if window exceeds size
        if (window.size() > size) {
            sum -= window.front();
            window.pop();
        }
        
        return sum / window.size();
    }
};
```
