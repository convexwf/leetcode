# 剑指 Offer II JZ076-数组中的第 k 大的数字

## 题目描述

<!-- description:start -->

<p>给定整数数组 <code>nums</code> 和整数 <code>k</code>，请返回数组中第 <code><strong>k</strong></code> 个最大的元素。</p>

<p>请注意，你需要找的是数组排序后的第 <code>k</code> 个最大的元素，而不是第 <code>k</code> 个不同的元素。</p>

<p>&nbsp;</p>

<p><strong>示例 1:</strong></p>

<pre>
<strong>输入:</strong> <code>[3,2,1,5,6,4] 和</code> k = 2
<strong>输出:</strong> 5
</pre>

<p><strong>示例&nbsp;2:</strong></p>

<pre>
<strong>输入:</strong> <code>[3,2,3,1,2,4,5,5,6] 和</code> k = 4
<strong>输出:</strong> 4</pre>

<p>&nbsp;</p>

<p><strong>提示： </strong></p>

<ul>
	<li><code>1 &lt;= k &lt;= nums.length &lt;= 10<sup>4</sup></code></li>
	<li><code>-10<sup>4</sup>&nbsp;&lt;= nums[i] &lt;= 10<sup>4</sup></code></li>
</ul>

<p>&nbsp;</p>

## Code

1. 使用快速选择算法（QuickSelect），基于快速排序的分区思想。
2. 随机选择一个基准值，将数组分为左右两部分，左边大于基准值，右边小于基准值。
3. 根据分区位置与 k 的关系，决定在左边或右边继续查找。
4. 也可使用小根堆维护 k 个最大元素。
5. 快速选择平均时间复杂度 $O(n)$，最坏 $O(n^2)$，空间复杂度 $O(1)$。

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        return quickSelect(nums, 0, nums.size() - 1, k);
    }
    
private:
    int quickSelect(vector<int>& nums, int left, int right, int k) {
        if (left == right) return nums[left];
        
        int pivotIndex = partition(nums, left, right);
        int rank = pivotIndex - left + 1; // Rank of pivot in current range
        
        if (rank == k) {
            return nums[pivotIndex];
        } else if (rank > k) {
            return quickSelect(nums, left, pivotIndex - 1, k);
        } else {
            return quickSelect(nums, pivotIndex + 1, right, k - rank);
        }
    }
    
    int partition(vector<int>& nums, int left, int right) {
        // Random pivot for better average performance
        int randomIndex = left + rand() % (right - left + 1);
        swap(nums[randomIndex], nums[right]);
        
        int pivot = nums[right];
        int i = left;
        
        for (int j = left; j < right; ++j) {
            if (nums[j] > pivot) { // Descending order for kth largest
                swap(nums[i], nums[j]);
                ++i;
            }
        }
        
        swap(nums[i], nums[right]);
        return i;
    }
};
```
