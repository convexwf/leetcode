# 剑指 Offer II JZ022-链表中环的入口节点

## 题目描述

<!-- description:start -->

## 解题思路

1. 使用快慢指针检测环：慢指针每次走一步，快指针每次走两步。
2. 如果有环，快慢指针一定会在环中相遇。
3. 相遇后，将一个指针移到链表头部，两个指针都以每次一步的速度移动。
4. 再次相遇的节点就是环的入口节点。
5. 数学证明：设头到入口距离为a，入口到相遇点距离为b，相遇点到入口距离为c，则有2(a+b)=a+b+n(b+c)，化简得a=c+(n-1)(b+c)。

时间复杂度：$O(n)$，快慢指针最多遍历链表两次。空间复杂度：$O(1)$，只使用两个指针。

```cpp
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        if (head == nullptr || head->next == nullptr) {
            return nullptr;
        }
        
        ListNode* slow = head;
        ListNode* fast = head;
        
        // Find meeting point
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            
            if (slow == fast) {
                // Found cycle, find entrance
                ListNode* ptr = head;
                while (ptr != slow) {
                    ptr = ptr->next;
                    slow = slow->next;
                }
                return ptr;
            }
        }
        
        return nullptr;
    }
};
```
