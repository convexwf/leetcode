# 剑指 Offer II JZ094-最少回文分割

## 题目描述

<p>返回符合要求的 <strong>最少分割次数</strong> 。</p>

## Code

1. 使用动态规划，`dp[i]` 表示字符串前 `i` 个字符的最少分割次数。
2. 预处理回文判断，`isPalin[i][j]` 表示子串 `s[i:j+1]` 是否为回文串。
3. 如果 `s[0:i+1]` 本身是回文串，则 `dp[i] = 0`。
4. 否则枚举分割点 `j`，如果 `s[j+1:i+1]` 是回文串，则 `dp[i] = min(dp[i], dp[j] + 1)`。
5. 时间复杂度 $O(n^2)$，空间复杂度 $O(n^2)$。

```cpp
class Solution {
public:
    int minCut(string s) {
        int n = s.size();
        vector<vector<bool>> isPalin(n, vector<bool>(n, false));
        
        // Preprocess palindrome check
        for (int i = n - 1; i >= 0; --i) {
            for (int j = i; j < n; ++j) {
                if (s[i] == s[j] && (j - i <= 1 || isPalin[i + 1][j - 1])) {
                    isPalin[i][j] = true;
                }
            }
        }
        
        vector<int> dp(n, INT_MAX);
        for (int i = 0; i < n; ++i) {
            if (isPalin[0][i]) {
                dp[i] = 0;
            } else {
                for (int j = 0; j < i; ++j) {
                    if (isPalin[j + 1][i]) {
                        dp[i] = min(dp[i], dp[j] + 1);
                    }
                }
            }
        }
        
        return dp[n - 1];
    }
};
```
