# 剑指 Offer II JZ051-节点之和最大的路径

## 题目描述

<!-- description:start -->

<p><strong>路径</strong> 被定义为一条从树中任意节点出发，沿父节点-子节点连接，达到任意节点的序列。同一个节点在一条路径序列中 <strong>至多出现一次</strong> 。该路径<strong> 至少包含一个 </strong>节点，且不一定经过根节点。</p>

<p><strong>路径和</strong> 是路径中各节点值的总和。</p>

<p>给定一个二叉树的根节点 <code>root</code> ，返回其 <strong>最大路径和</strong>，即所有路径上节点值之和的最大值。</p>

## Code

1. 使用递归的深度优先搜索 `dfs` 函数遍历整棵树，返回从该节点往下的最大路径和。
2. 对于每个节点，递归计算左子树和右子树的最大贡献值，如果为负数则取 0。
3. 在递归过程中，更新全局最大路径和为 `当前节点值 + 左子树贡献 + 右子树贡献`。
4. 返回 `当前节点值 + max(左子树贡献, 右子树贡献)` 作为该节点的最大贡献值。

时间复杂度：$O(n)$，其中 $n$ 是二叉树的节点数，需要遍历所有节点。空间复杂度：$O(h)$，其中 $h$ 是树的高度，递归调用栈的深度。

```cpp
class Solution {
private:
    int maxSum = INT_MIN;
    
    int dfs(TreeNode* root) {
        if (root == nullptr) return 0;
        
        // Calculate max contribution from left and right subtrees
        // Take 0 if negative (don't include negative path)
        int leftGain = max(0, dfs(root->left));
        int rightGain = max(0, dfs(root->right));
        
        // Update global max with path through current node
        int pathSum = root->val + leftGain + rightGain;
        maxSum = max(maxSum, pathSum);
        
        // Return max gain from current node (can only go one way)
        return root->val + max(leftGain, rightGain);
    }
    
public:
    int maxPathSum(TreeNode* root) {
        dfs(root);
        return maxSum;
    }
};
```
3. 更新全局最大路径和：`maxSum = max(maxSum, node->val + leftMax + rightMax)`，考虑路径经过当前节点的情况。
4. 返回该节点往下的最大单边路径和：`node->val + max(leftMax, rightMax)`。
5. 最终返回全局最大路径和 `maxSum`。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxPathSum(TreeNode* root) {
        int maxSum = INT_MIN;
        dfs(root, maxSum);
        return maxSum;
    }

private:
    int dfs(TreeNode* node, int& maxSum) {
        if (!node) {
            return 0;
        }

        int leftMax = std::max(0, dfs(node->left, maxSum));
        int rightMax = std::max(0, dfs(node->right, maxSum));

        maxSum = std::max(maxSum, node->val + leftMax + rightMax);

        return node->val + std::max(leftMax, rightMax);
    }
};
```
