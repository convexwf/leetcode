# 剑指 Offer II JZ014-字符串中的变位词

## 题目描述

<!-- description:start -->

<p>给定两个字符串&nbsp;<code>s1</code>&nbsp;和&nbsp;<code>s2</code>，写一个函数来判断 <code>s2</code> 是否包含 <code>s1</code><strong>&nbsp;</strong>的某个变位词。</p>

<p>换句话说，第一个字符串的排列之一是第二个字符串的 <strong>子串</strong> 。</p>

<p>&nbsp;</p>

<p><strong>示例 1：</strong></p>

<pre>
<strong>输入: </strong>s1 = &quot;ab&quot; s2 = &quot;eidbaooo&quot;
<strong>输出: </strong>True
<strong>解释:</strong> s2 包含 s1 的排列之一 (&quot;ba&quot;).
</pre>

<p><strong>示例 2：</strong></p>

<pre>
<strong>输入: </strong>s1= &quot;ab&quot; s2 = &quot;eidboaoo&quot;
<strong>输出:</strong> False
</pre>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>1 &lt;= s1.length, s2.length &lt;= 10<sup>4</sup></code></li>
	<li><code>s1</code> 和 <code>s2</code> 仅包含小写字母</li>
</ul>

<p>&nbsp;</p>

## Code

1. 使用滑动窗口和字符频次统计来判断 `s2` 是否包含 `s1` 的变位词。
2. 首先统计 `s1` 中每个字符的出现次数，存储在数组 `cnt1` 中。
3. 维护一个长度为 `s1.length()` 的滑动窗口在 `s2` 上移动，统计窗口内字符频次到 `cnt2`。
4. 每次移动窗口时，添加新字符并移除旧字符，更新 `cnt2`。
5. 如果某个窗口的字符频次 `cnt2` 与 `cnt1` 完全相同，说明找到了变位词，返回 `true`。

```cpp
class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        if (s1.length() > s2.length()) {
            return false;
        }
        
        vector<int> cnt1(26, 0), cnt2(26, 0);
        
        // Count frequency of characters in s1
        for (char c : s1) {
            cnt1[c - 'a']++;
        }
        
        // Initialize the first window in s2
        for (int i = 0; i < s1.length(); ++i) {
            cnt2[s2[i] - 'a']++;
        }
        
        // Check if the first window matches
        if (cnt1 == cnt2) {
            return true;
        }
        
        // Slide the window
        for (int i = s1.length(); i < s2.length(); ++i) {
            cnt2[s2[i] - 'a']++;                        // Add new character
            cnt2[s2[i - s1.length()] - 'a']--;         // Remove old character
            
            if (cnt1 == cnt2) {
                return true;
            }
        }
        
        return false;
    }
};
```
