# 剑指 Offer II JZ025-链表中的两数相加

## 题目描述

<!-- description:start -->

<p>给定两个 <strong>非空链表</strong> <code>l1</code>和 <code>l2</code>&nbsp;来代表两个非负整数。数字最高位位于链表开始位置。它们的每个节点只存储一位数字。将这两数相加会返回一个新的链表。</p>

<p>可以假设除了数字 0 之外，这两个数字都不会以零开头。</p>

</pre>

<pre>

## 解题思路

1. 使用两个栈分别存储两个链表的节点值（从高位到低位）。
2. 从栈顶开始弹出（即从低位开始），模拟加法运算。
3. 计算每一位的和以及进位。
4. 使用头插法构建结果链表（因为是从低位到高位计算）。
5. 处理最后的进位。

时间复杂度：$O(m + n)$，其中 $m$ 和 $n$ 是两个链表的长度。空间复杂度：$O(m + n)$，需要两个栈存储节点值。

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        stack<int> s1, s2;
        
        // Push all values to stacks
        while (l1 != nullptr) {
            s1.push(l1->val);
            l1 = l1->next;
        }
        while (l2 != nullptr) {
            s2.push(l2->val);
            l2 = l2->next;
        }
        
        // Add from least significant digit
        int carry = 0;
        ListNode* result = nullptr;
        
        while (!s1.empty() || !s2.empty() || carry > 0) {
            int sum = carry;
            if (!s1.empty()) {
                sum += s1.top();
                s1.pop();
            }
            if (!s2.empty()) {
                sum += s2.top();
                s2.pop();
            }
            
            carry = sum / 10;
            
            // Insert at head
            ListNode* node = new ListNode(sum % 10);
            node->next = result;
            result = node;
        }
        
        return result;
    }
};
```
