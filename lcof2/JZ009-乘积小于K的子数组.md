# 剑指 Offer II JZ009-乘积小于 K 的子数组

## 题目描述

<!-- description:start -->

<p>给定一个正整数数组&nbsp;<code>nums</code>和整数 <code>k</code>&nbsp;，请找出该数组内乘积小于&nbsp;<code>k</code>&nbsp;的连续的子数组的个数。</p>

<p>&nbsp;</p>

<p><strong>示例 1:</strong></p>

<pre>
<strong>输入:</strong> nums = [10,5,2,6], k = 100
<strong>输出:</strong> 8
<strong>解释:</strong> 8 个乘积小于 100 的子数组分别为: [10], [5], [2], [6], [10,5], [5,2], [2,6], [5,2,6]。
需要注意的是 [10,5,2] 并不是乘积小于100的子数组。
</pre>

<p><strong>示例 2:</strong></p>

<pre>
<strong>输入:</strong> nums = [1,2,3], k = 0
<strong>输出:</strong> 0</pre>

<p>&nbsp;</p>

<p><strong>提示:&nbsp;</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 3 * 10<sup>4</sup></code></li>
	<li><code>1 &lt;= nums[i] &lt;= 1000</code></li>
	<li><code>0 &lt;= k &lt;= 10<sup>6</sup></code></li>
</ul>

<p>&nbsp;</p>

## Code

1. 如果 `k <= 1`，直接返回 0，因为所有正整数的乘积至少为 1。
2. 使用滑动窗口的双指针方法，维护 `left` 和 `right` 两个指针和窗口内的乘积 `product`。
3. 右指针不断右移，将新元素乘入 `product`，当 `product >= k` 时，左指针右移缩小窗口。
4. 每次右指针移动后，以 `right` 为终点的子数组有 `right - left + 1` 个，累加到结果中。
5. 时间复杂度 $O(n)$，空间复杂度 $O(1)$。

```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        if (k <= 1) return 0;
        int left = 0, right = 0;
        int product = 1;
        int result = 0;
        int n = nums.size();

        while (right < n) {
            product *= nums[right];

            while (product >= k) {
                product /= nums[left];
                left++;
            }

            result += right - left + 1;
            right++;
        }

        return result;
    }
};
```
