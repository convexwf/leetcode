# 剑指 Offer II JZ072-求平方根

## Code

1. 使用二分查找算法在 `[0, x]` 范围内查找平方根。
2. 先处理特殊情况：当 `x` 为 0 或 1 时，直接返回 `x`。
3. 在二分查找过程中，比较 `mid * mid` 和 `x` 的大小，为避免溢出使用 `mid <= x / mid` 判断。
4. 如果 `mid` 的平方小于等于 `x`，则左边界右移；否则右边界左移。
5. 最后返回 `right`，时间复杂度 $O(\log x)$。

```cpp
class Solution {
public:
    int mySqrt(int x) {
        if (x == 0 || x == 1) {
            return x;
        }
        
        int left = 0, right = x;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (mid <= x / mid) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        
        return right - 1;
    }
};
