## Code

1. 使用归并排序，通过快慢指针找到链表中点。
2. 将链表分为两半，分别对左右两部分递归排序。
3. 合并两个有序链表，使用双指针比较节点值。
4. 注意断开中间链接，避免循环引用。
5. 时间复杂度 $O(n\log n)$，空间复杂度 $O(\log n)$（递归栈）。

```cpp
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;
        
        // Find middle using slow/fast pointers
        ListNode* slow = head;
        ListNode* fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        // Split the list
        ListNode* mid = slow->next;
        slow->next = nullptr;
        
        // Sort both halves
        ListNode* left = sortList(head);
        ListNode* right = sortList(mid);
        
        // Merge sorted lists
        return merge(left, right);
    }
    
private:
    ListNode* merge(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);
        ListNode* curr = &dummy;
        
        while (l1 && l2) {
            if (l1->val < l2->val) {
                curr->next = l1;
                l1 = l1->next;
            } else {
                curr->next = l2;
                l2 = l2->next;
            }
            curr = curr->next;
        }
        
        curr->next = l1 ? l1 : l2;
        return dummy.next;
    }
};
```
