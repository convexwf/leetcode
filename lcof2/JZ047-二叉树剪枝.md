## 解题思路

1. 使用后序遍历（左-右-根）的方式递归处理每个节点。
2. 先递归处理左右子树，将子树中所有值为 0 的子树剪除。
3. 处理当前节点：如果当前节点值为 0 且左右子树都为空，则该节点应被剪除（返回 `nullptr`）。
4. 否则保留当前节点。

时间复杂度：$O(n)$，其中 $n$ 是二叉树的节点数，需要遍历所有节点。空间复杂度：$O(h)$，其中 $h$ 是树的高度，递归调用栈的深度。

```cpp
class Solution {
public:
    TreeNode* pruneTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        
        // Recursively prune left and right subtrees
        root->left = pruneTree(root->left);
        root->right = pruneTree(root->right);
        
        // If current node is 0 and has no children, prune it
        if (root->val == 0 && root->left == nullptr && root->right == nullptr) {
            return nullptr;
        }
        
        return root;
    }
};
```
