# 剑指 Offer II JZ085-生成匹配的括号

## 题目描述

<!-- description:start -->

<p>正整数&nbsp;<code>n</code>&nbsp;代表生成括号的对数，请设计一个函数，用于能够生成所有可能的并且 <strong>有效的 </strong>括号组合。</p>

<p>&nbsp;</p>

<p><strong>示例 1：</strong></p>

<pre>
<strong>输入：</strong>n = 3
<strong>输出：</strong>[&quot;((()))&quot;,&quot;(()())&quot;,&quot;(())()&quot;,&quot;()(())&quot;,&quot;()()()&quot;]
</pre>

<p><strong>示例 2：</strong></p>

<pre>
<strong>输入：</strong>n = 1
<strong>输出：</strong>[&quot;()&quot;]
</pre>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>1 &lt;= n &lt;= 8</code></li>
</ul>

<p>&nbsp;</p>

## Code

1. 使用回溯算法，维护当前左括号和右括号的数量。
2. 如果左括号数量小于 `n`，可以添加左括号。
3. 如果右括号数量小于左括号数量，可以添加右括号。
4. 当左右括号数量都达到 `n` 时，将当前字符串加入结果集。
5. 时间复杂度 $O(\frac{4^n}{\sqrt{n}})$，为第 `n` 个卡特兰数。

```cpp
class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<string> result;
        string current;
        backtrack(n, 0, 0, current, result);
        return result;
    }
    
private:
    void backtrack(int n, int left, int right, string& current, vector<string>& result) {
        if (current.size() == 2 * n) {
            result.push_back(current);
            return;
        }
        
        if (left < n) {
            current.push_back('(');
            backtrack(n, left + 1, right, current, result);
            current.pop_back();
        }
        
        if (right < left) {
            current.push_back(')');
            backtrack(n, left, right + 1, current, result);
            current.pop_back();
        }
    }
};
```
