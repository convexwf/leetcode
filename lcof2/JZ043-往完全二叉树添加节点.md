# 剑指 Offer II JZ043-往完全二叉树添加节点

## 题目描述

<!-- description:start -->

<p>完全二叉树是每一层（除最后一层外）都是完全填充（即，节点数达到最大，第 <code>n</code> 层有 <code>2<sup>n-1</sup></code>&nbsp;个节点）的，并且所有的节点都尽可能地集中在左侧。</p>

<p>设计一个用完全二叉树初始化的数据结构&nbsp;<code>CBTInserter</code>，它支持以下几种操作：</p>

<ul>
	<li><code>CBTInserter(TreeNode root)</code>&nbsp;使用根节点为&nbsp;<code>root</code>&nbsp;的给定树初始化该数据结构；</li>
	<li><code>CBTInserter.insert(int v)</code>&nbsp; 向树中插入一个新节点，节点类型为 <code>TreeNode</code>，值为 <code>v</code> 。使树保持完全二叉树的状态，<strong>并返回插入的新节点的父节点的值</strong>；</li>
	<li><code>CBTInserter.get_root()</code> 将返回树的根节点。</li>
</ul>

<p>&nbsp;</p>

</ol>

<pre>
<strong>输入：</strong>inputs = [&quot;CBTInserter&quot;,&quot;insert&quot;,&quot;get_root&quot;], inputs = [[[1]],[2],[]]
<strong>输出：</strong>[null,1,[1,2]]

<strong>输出：</strong>[null,3,4,[1,2,3,4,5,6,7,8]]

## 解题思路

1. 使用队列维护所有未满的节点（左右子节点至少有一个为空）。
2. 初始化时，层序遍历整棵树，将所有未满的节点加入队列。
3. 插入新节点时，取队首节点作为父节点，优先插入左子节点，如果左子节点已存在则插入右子节点。
4. 如果父节点的两个子节点都已存在，将其从队列中移除，新节点加入队列。
5. 返回父节点的值。

时间复杂度：初始化 $O(n)$，插入 $O(1)$。空间复杂度：$O(n)$，需要存储所有未满的节点。

```cpp
class CBTInserter {
private:
    TreeNode* root;
    queue<TreeNode*> q;
    
public:
    CBTInserter(TreeNode* root) {
        this->root = root;
        queue<TreeNode*> temp;
        temp.push(root);
        
        // Initialize queue with incomplete nodes
        while (!temp.empty()) {
            TreeNode* node = temp.front();
            temp.pop();
            
            if (node->left) temp.push(node->left);
            if (node->right) temp.push(node->right);
            
            // Add to q if not complete
            if (!node->left || !node->right) {
                q.push(node);
            }
        }
    }
    
    int insert(int v) {
        TreeNode* newNode = new TreeNode(v);
        TreeNode* parent = q.front();
        
        // Insert as left or right child
        if (!parent->left) {
            parent->left = newNode;
        } else {
            parent->right = newNode;
            q.pop(); // Parent is now complete
        }
        
        q.push(newNode);
        return parent->val;
    }
    
    TreeNode* get_root() {
        return root;
    }
};
```
