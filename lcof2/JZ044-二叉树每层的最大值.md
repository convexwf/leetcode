## 解题思路

1. 使用层序遍历（BFS），用队列按层遍历二叉树。
2. 对于每一层，遍历该层所有节点，记录该层的最大值。
3. 将每层的最大值添加到结果数组中。
4. 继续处理下一层，直到遍历完所有层。

时间复杂度：$O(n)$，其中 $n$ 是二叉树的节点数，需要遍历所有节点。空间复杂度：$O(w)$，其中 $w$ 是树的最大宽度，队列最多存储一层的节点。

```cpp
class Solution {
public:
    vector<int> largestValues(TreeNode* root) {
        vector<int> result;
        if (root == nullptr) return result;
        
        queue<TreeNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            int levelSize = q.size();
            int maxVal = INT_MIN;
            
            for (int i = 0; i < levelSize; i++) {
                TreeNode* node = q.front();
                q.pop();
                
                maxVal = max(maxVal, node->val);
                
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            
            result.push_back(maxVal);
        }
        
        return result;
    }
};
```
