## 解题思路

1. 使用双指针技巧，设置一个虚拟头节点方便处理删除头节点的情况。
2. 快指针先走n步。
3. 然后快慢指针同时走，直到快指针到达链表末尾。
4. 此时慢指针指向待删除节点的前一个节点。
5. 删除倒数第n个节点并返回头节点。

时间复杂度：$O(n)$，只需要遍历一次链表。空间复杂度：$O(1)$，只使用常数额外空间。

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummy = new ListNode(0);
        dummy->next = head;
        
        ListNode* fast = dummy;
        ListNode* slow = dummy;
        
        // Move fast pointer n steps ahead
        for (int i = 0; i <= n; i++) {
            fast = fast->next;
        }
        
        // Move both pointers until fast reaches end
        while (fast != nullptr) {
            fast = fast->next;
            slow = slow->next;
        }
        
        // Remove the nth node from end
        ListNode* toDelete = slow->next;
        slow->next = slow->next->next;
        delete toDelete;
        
        ListNode* result = dummy->next;
        delete dummy;
        return result;
    }
};
```
