# 剑指 Offer II JZ010-和为 k 的子数组

## 题目描述

<!-- description:start -->

<p>给定一个正整数数组和一个整数&nbsp;<code>k</code><strong> ，</strong>请找到该数组中和为&nbsp;<code>k</code><strong>&nbsp;</strong>的连续子数组的个数。</p>

<p>&nbsp;</p>

<p><strong>示例 1 :</strong></p>

<pre>
<strong>输入:</strong>nums = [1,1,1], k = 2
<strong>输出:</strong> 2
<strong>解释:</strong> 此题 [1,1] 与 [1,1] 为两种不同的情况
</pre>

<p><strong>示例 2&nbsp;:</strong></p>

<pre>
<strong>输入:</strong>nums = [1,2,3], k = 3
<strong>输出:</strong> 2
</pre>

<p>&nbsp;</p>

<p><strong>提示:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 2 * 10<sup>4</sup></code></li>
	<li><code>1000 &lt;= nums[i] &lt;= 1000</code></li>
	<li>
	<p><code>-10<sup>7</sup>&nbsp;&lt;= k &lt;= 10<sup>7</sup></code></p>
	</li>
</ul>

<p>&nbsp;</p>

## 解题思路

1. 使用前缀和+哈希表的方法，`preSum[i]`表示前i个元素的和。
2. 如果`preSum[j] - preSum[i] = k`，则子数组`[i+1...j]`的和为k。
3. 使用哈希表存储每个前缀和出现的次数，边遍历边统计。
4. 对于当前位置j，查找有多少个位置i满足`preSum[i] = preSum[j] - k`。
5. 累加所有满足条件的子数组个数。

时间复杂度：$O(n)$，遍历数组一次。空间复杂度：$O(n)$，哈希表存储前缀和。

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> preSumCount;
        preSumCount[0] = 1;  // Empty prefix sum
        
        int preSum = 0;
        int count = 0;
        
        for (int num : nums) {
            preSum += num;
            
            // Check if there exists a prefix sum that makes current sum - prefix = k
            if (preSumCount.count(preSum - k)) {
                count += preSumCount[preSum - k];
            }
            
            preSumCount[preSum]++;
        }
        
        return count;
    }
};
```
