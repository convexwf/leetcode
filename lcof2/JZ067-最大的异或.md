# 剑指 Offer II JZ067-最大的异或

## 题目描述

<!-- description:start -->

<p>给定一个整数数组 <code>nums</code> ，返回<em> </em><code>nums[i] XOR nums[j]</code> 的最大运算结果，其中 <code>0 &le; i &le; j &lt; n</code> 。</p>

## Code

1. 使用前缀树（Trie）存储所有数字的二进制表示。
2. 对于每个数，尝试在 Trie 中找到与它异或结果最大的数。
3. 从最高位开始，尽可能选择与当前位相反的路径（使异或值最大）。
4. 如果不存在相反的路径，则选择相同的路径。
5. 时间复杂度 $O(n \cdot 31)$，空间复杂度 $O(n \cdot 31)$。

```cpp
class TrieNode {
public:
    TrieNode* children[2];
    TrieNode() {
        children[0] = nullptr;
        children[1] = nullptr;
    }
};

class Solution {
public:
    int findMaximumXOR(vector<int>& nums) {
        TrieNode* root = new TrieNode();
        
        // Build Trie
        for (int num : nums) {
            TrieNode* node = root;
            for (int i = 30; i >= 0; --i) {
                int bit = (num >> i) & 1;
                if (!node->children[bit]) {
                    node->children[bit] = new TrieNode();
                }
                node = node->children[bit];
            }
        }
        
        int maxXor = 0;
        // Find maximum XOR for each number
        for (int num : nums) {
            TrieNode* node = root;
            int currentXor = 0;
            for (int i = 30; i >= 0; --i) {
                int bit = (num >> i) & 1;
                // Try to go opposite direction for maximum XOR
                int oppositeBit = 1 - bit;
                if (node->children[oppositeBit]) {
                    currentXor |= (1 << i);
                    node = node->children[oppositeBit];
                } else {
                    node = node->children[bit];
                }
            }
            maxXor = max(maxXor, currentXor);
        }
        
        return maxXor;
    }
};
```
