## 解题思路

1. 利用二叉搜索树的性质，使用反向中序遍历（右-根-左），这样可以按从大到小的顺序访问所有节点。
2. 维护一个累加和 `sum`，记录已经访问过的所有节点值之和。
3. 对每个访问到的节点，将其值累加到 `sum` 上,然后更新该节点的值为 `sum`。
4. 继续递归处理右子树和左子树。

时间复杂度：$O(n)$，其中 $n$ 是二叉树的节点数，需要遍历所有节点。空间复杂度：$O(h)$，其中 $h$ 是树的高度，递归调用栈的深度。

```cpp
class Solution {
private:
    int sum = 0;
    
public:
    TreeNode* convertBST(TreeNode* root) {
        // Reverse inorder traversal: right -> root -> left
        if (root == nullptr) return nullptr;
        
        // Process right subtree first (larger values)
        convertBST(root->right);
        
        // Update current node value with cumulative sum
        sum += root->val;
        root->val = sum;
        
        // Process left subtree (smaller values)
        convertBST(root->left);
        
        return root;
    }
};
```
