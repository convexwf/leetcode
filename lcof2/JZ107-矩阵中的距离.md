# 剑指 Offer II JZ107-矩阵中的距离

## 题目描述

<!-- description:start -->

<p>给定一个由 <code>0</code> 和 <code>1</code> 组成的矩阵 <code>mat</code>&nbsp;，请输出一个大小相同的矩阵，其中每一个格子是 <code>mat</code> 中对应位置元素到最近的 <code>0</code> 的距离。</p>

<p>两个相邻元素间的距离为 <code>1</code> 。</p>

</pre>

## Code

1. 使用多源 BFS，将所有为 0 的位置作为起点同时加入队列。
2. 初始化结果矩阵，将所有 0 的位置设为 0，其他位置设为无穷大。
3. 从所有 0 的位置开始同时进行 BFS，向四个方向扩展。
4. 对于每个相邻位置，更新其距离为当前距离加 1。
5. 最终每个位置都会被更新为到最近 0 的距离。

```cpp
class Solution {
public:
    vector<vector<int>> updateMatrix(vector<vector<int>>& mat) {
        int m = mat.size();
        int n = mat[0].size();
        vector<vector<int>> result(m, vector<int>(n, INT_MAX));
        queue<pair<int, int>> q;
        
        // Initialize: add all 0 positions to queue
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (mat[i][j] == 0) {
                    result[i][j] = 0;
                    q.push({i, j});
                }
            }
        }
        
        // BFS
        vector<pair<int, int>> directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        while (!q.empty()) {
            auto [i, j] = q.front();
            q.pop();
            
            for (auto [di, dj] : directions) {
                int ni = i + di;
                int nj = j + dj;
                
                if (ni >= 0 && ni < m && nj >= 0 && nj < n) {
                    if (result[ni][nj] > result[i][j] + 1) {
                        result[ni][nj] = result[i][j] + 1;
                        q.push({ni, nj});
                    }
                }
            }
        }
        
        return result;
    }
};
```
