# 1542C. Strange Function

## Solution

以 `n = 10` 为例，可以观察到：

- 考虑因子 `1`，所有数字都能被 `1` 整除，所以贡献为 0；
- 考虑因子 `2`，有 `5` 个数字不能被 `2` 整除，贡献为 `5 * 2 = 10`；
- 考虑因子 `3`，在剩余的 `5` 个数字中，只有 `6` 能被 `3` 整除，所以有 4 个数字不能被 `3` 整除，贡献为 `4 * 3 = 12`；
- 考虑因子 `4`，在剩余的 `1` 个数字中，`6` 不能被 `4` 整除，贡献为 `1 * 4 = 4`；
- 最终贡献为 `0 + 10 + 12 + 4 = 26`。

换个思路思考，因子从 `2` 开始，每次加 `1`，假如当前因子为 `k` ：

1. 每次都需要在剩余数字里计算有多少数字能被当前因子整除，所以需要计算 `factor = lcm(2, 3, ..., k)`
2. 计算 `satisfy = n / factor`，表示有多少数字能被当前因子整除，即经过这 `k` 个因子筛选后剩余的数字个数；
3. 当前因子的贡献为 `(bucket_size - satisfy) * k`，其中 `bucket_size` 表示当前剩余的数字个数，初始时 `bucket_size = n`；
4. 更新 `bucket_size = satisfy`，回到步骤 1，直到 `bucket_size` 为 `0`。
