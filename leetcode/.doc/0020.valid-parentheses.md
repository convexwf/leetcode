## Solution

**题目描述**

验证输入的字符串是否为有效的括号字符串，括号包括大括号，中括号和小括号。

**解题思路**

1. 栈
    - 遍历输入字符串，如果当前字符为左半边括号时，则将其压入栈中，
    - 如果遇到右半边括号时，若此时栈为空，则直接返回 false，如不为空，则取出栈顶元素，若为对应的左半边括号，则继续循环，反之返回 false
    - 如果循环结束时栈为空，则返回 true，反之返回 false
    - 时间复杂度为 $O(n)$ ，空间复杂度为 $O(n)$ 。

**测试用例**

- `s = ""`
- `s = "()"`
- `s = "()[]{}"`
- `s = "(]"`
- `s = "([)]"`
- `s = "{[]}"`

## summary

Let me restate the problem first. We need to determine if a string containing only parentheses characters '(', ')', '{', '}', '[' and ']' is valid. A string is valid if open brackets are closed by the same type of brackets in the correct order.

The key idea is to use a stack data structure. When we encounter an opening bracket, we push it onto the stack. When we encounter a closing bracket, we check if it matches the most recent unmatched opening bracket (stack top).

Here's the algorithm step-by-step:

1. Initialize an empty stack
2. Iterate through each character in the string
3. If it's an opening bracket '(', '[', or '{', push it onto the stack
4. If it's a closing bracket ')', ']', or '}', check if the stack is empty or if the top doesn't match - if so, return false
5. If it matches, pop the stack and continue
6. After processing all characters, return true if the stack is empty, false otherwise

This approach takes linear time O(n) and linear space O(n) in the worst case.

For example, given s = "()[]{}", we push '(' then immediately match it with ')', push '[' then match with ']', push '{' then match with '}'. The stack ends up empty, so we return true.

## Code

### C++

```cpp
// 1. 栈
// 2022-07-19 submission
// 92/92 cases passed
// Runtime: 0 ms, faster than 100% of cpp online submissions.
// Memory Usage: 6.2 MB, less than 95.98% of cpp online submissions.
class Solution {
public:
    bool isValid(string s) {
        stack<char> parentheses;
        for (int i = 0; i < s.size(); ++i) {
            if (s[i] == '(' || s[i] == '[' || s[i] == '{')
                parentheses.push(s[i]);
            else {
                if (parentheses.empty()) return false;
                if (s[i] == ')' && parentheses.top() != '(') return false;
                if (s[i] == ']' && parentheses.top() != '[') return false;
                if (s[i] == '}' && parentheses.top() != '{') return false;
                parentheses.pop();
            }
        }
        return parentheses.empty();
    }
};
```
